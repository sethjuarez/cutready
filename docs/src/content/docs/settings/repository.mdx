The **Git Remote** tab in Workspace Settings configures remote sync for your
workspace. This is where you connect to a GitHub repository and set
authentication.

<Aside type="note">
  Remote settings are per-workspace, not global. Open them from the **monitor
  icon** (🖥️) in the sidebar, then select the **Git Remote** tab.
</Aside>

## Remote URL

Enter the HTTPS or SSH URL of your GitHub repository:

```text
https://github.com/your-username/your-workspace.git
```

Click **Test Connection** to verify CutReady can reach the remote with your
chosen authentication method.

## Authentication

Choose how CutReady authenticates with your remote:

### GitHub CLI (Recommended)

If you have the [GitHub CLI](https://cli.github.com/) installed and authenticated
(`gh auth login`), CutReady automatically uses your credentials. This is the
simplest option — no tokens or keys to manage.

### Personal Access Token (PAT)

Generate a [fine-grained token](https://github.com/settings/tokens?type=beta)
with **Contents: Read and write** permission for your repository. Paste it
into the token field. The token is stored in the encrypted Stronghold vault.

### SSH Key

CutReady uses Draftline remote support with your system SSH keys. Make sure
your SSH key is added to your GitHub account and available in your system's SSH
agent.

## Snapshot Identity

Snapshots show who saved them. The name and email come from
**Settings** → **Profile**, which is per person rather than per workspace.
See [Profile](/settings/overview/#profile) for how CutReady picks them.

## When to Configure

You only need remote settings if you want to:

- **Back up** your workspace to GitHub
- **Sync** across multiple devices
- **Collaborate** with others on the same workspace
- **Open pull requests** from timelines

If you're working solo on a single machine, you can skip this entirely —
CutReady's snapshot and timeline features work fully offline.
